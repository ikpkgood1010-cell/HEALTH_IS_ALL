# NOTIFICATION ENGINE

Version: 1.0

---

# Purpose

This document defines how Guild Health delivers timely, meaningful, and supportive notifications.

Notifications exist to encourage healthy behavior, not to maximize engagement.

Health always has higher priority than retention metrics.

# Personalization

---

# AI Notification Rules

AI may recommend:

Exercise

Hydration

Recovery

Nutrition

Rest

Mental wellness

AI must not generate fear-based notifications.

AI should explain recommendations whenever appropriate.

---

# Notification Fatigue

The system should reduce unnecessary notifications.

Repeated ignored notifications should decrease in frequency.

Completed habits should cancel unnecessary reminders.

---

# Security Notifications

Always notify users about:

New Device Login

Password Change

Account Recovery

Permission Changes

Privacy Setting Changes
