# HEALTH TIPS TRICKS FEEDER SPECIFICATION V2

## Purpose
사용자에게 식단, 운동, 수면, 수분 섭취 등에 관한 1~3줄 분량의 유용하고 실용적인 꿀팁과 간단 정보를 지속적이고 재미있게 제공하는 피더 시스템의 명세이다.

## Scope
앱 메인 화면 팁 위젯, 푸시 알림, 정령 말풍선 콘텐츠 피드.

## SSOT
`HEALTH IS ALL/05_AI/HEALTH_TIPS_TRICKS_FEEDER_V2.md`

## Definitions
- **Short-Form Tip**: 1~3줄 이내로 직관적으로 이해하기 쉽게 구성된 핵심 건강 정보.

## Runtime
앱 실행 시, 탭 전환 시, 또는 백그라운드 타이머 이벤트에 따라 갱신.

## Rules
1. 모든 꿀팁은 반드시 1~3줄 이내로 작성하며, 모바일 화면 자동 줄바꿈(Auto Word-Wrap)이 완벽히 적용되어 잘림이 없어야 한다.
2. 식단 관련 꿀팁은 건강한 조리법(예: 찜, 구이) 및 대체 당/양념 활용 정보를 적극 포함한다.
3. 중복 노출을 최소화하기 위해 사용자 상태 및 시간대에 맞춰 팁을 동적으로 추출한다.

## State
- `FEEDING`: 신규 1~3줄 꿀팁 전달 중.
- `PAUSED`: 사용자 조작 중 피드 일시 정지.

## Event
- `ON_TIP_REQUEST`: UI에서 꿀팁 요청 시 발생.

## Example (1~3줄 꿀팁 샘플 라이브러리)
1. **[식단 팁]** 고기를 조리할 때 구이 대신 찜 방식을 활용해 보세요! 기름기는 빠지고 수분은 유지되어 더 건강하고 촉촉하게 즐길 수 있습니다. 🥩
2. **[당류 팁]** 설탕 대신 자일로스나 에리스리톨 같은 대체당을 적절히 활용하면, 단맛은 그대로 즐기면서 혈당 부담을 훨씬 줄일 수 있어요! 🍯
3. **[운동 팁]** 세차나 집안일 같은 일상 속 손활동도 훌륭한 칼로리 소모 운동입니다. 30분 동안 집중해서 움직이면 스트레칭 효과까지 얻을 수 있어요! 🚗

## Exception
팁 데이터베이스 로딩 실패 시 사전 내장된 로컬 기본 꿀팁 3종 중 하나를 무작위로 출력.
