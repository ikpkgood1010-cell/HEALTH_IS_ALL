# DEVELOPMENT ROADMAP

Version: 1.0

Development order: Foundation → Healthcare → Game System → Emotion System → Community → Optimization → Release.

1. Foundation: Next.js, strict TypeScript, Tailwind, shadcn/ui, quality tooling, Supabase, authentication, onboarding, theme, responsive shell.
2. Core Healthcare: exercise and food records, AI analysis, dashboard.
3. Statistics: daily to annual insights with Recharts.
4. RPG Foundation: guild, heroes, tower, automated exploration and battle.
5. Growth: EXP, points, equipment, guild upgrades.
6. Emotion: 건강이, affinity, diary, letters, camp and story.
7. Community: friends, leaderboards, guild ranking.
8. Achievement: achievements, titles, collections.
9. Season: rankings, rewards, events.
10. Optimization: performance, accessibility, security.
11. QA: unit, integration, E2E, release candidate.
12. Release: Vercel, Supabase, analytics, monitoring.
