# HEALTH_GAME_DUAL_BALANCE_SPEC_V5.md

## Purpose
본 명세서는 [헬스 이스 올] 앱 내에서 건강 관리 목적과 게임적 오락 요소 간의 균형을 유지하고, 게임이 건강 본연의 취지를 가리지 않도록 제어하는 듀얼 밸런스(Dual Balance) 정책 및 수식을 정의한다.

## Scope
* 건강 활동(식단, 운동, 수면, 수분)에 따른 게임 내 보상(EXP, 골드, 정령 친밀도) 지급 비율 조절
* 게임 몰입 과열 방지(Anti-Grind) 및 건강 행동 유도 메커니즘
* 사용자 인터페이스(UI) 팝업 대화의 호감도 높은 워딩 가이드라인

## SSOT
* **단일 진실 공급원 정의**: 본 문서는 게임 시스템과 건강 시스템 간의 상호작용 및 보상 계수 조절에 관한 SSOT 문서이다. 모든 게임 보상 밸런싱 작업은 본 문서에 기재된 규칙을 따른다.

## Definitions
1. **Health-First Rule (건강 우선 원칙)**: 앱 내 화면 표시 및 보상 구조에서 실제 건강 행동이 유발되지 않은 단순 게임 플레이만으로는 상위 보상을 획득할 수 없도록 제한하는 원칙.
2. **Cap Factor (상한 제어 계수)**: 하루에 건강 행동으로 얻을 수 있는 최대 게임 재화의 상한선. 과도한 운동이나 앱 남용을 방지함.

## Runtime
* **적용 시점**: 클라이언트 앱 내 미션 완료 팝업 표시 시 및 백엔드 보상 정산 시점.

## Rules
1. **1:1 대등한 품질 유지**: 게임 디자인의 완성도를 높이되, 메인 화면 UI에서 게임 요소가 건강 지표(운동, 식단 그래프)를 가리거나 과도하게 튀지 않도록 조화롭게 배치한다.
2. **동적 보상 산출 규칙**: 매일 똑같은 보상 수치가 제공되면 지루해지므로, 기상 시간 및 당일 활동 연속성에 따라 미세 가중치를 적용한다.
3. **호감 팝업 가이드**: 유저가 목표를 달성하지 못했을 때 억압적인 문구를 지양하고 친화적이고 응원하는 대화체만 사용한다.

## State
* `BALANCED`: 건강과 게임 요소가 정상적 듀얼 비율을 유지함.
* `HEALTH_WARNING`: 게임 플레이 시간이 길어지고 건강 행동 입력이 비어있을 때 알림 발송 상태.
* `CAP_REACHED`: 일일 최대 게임 보상 획득량 도달 상태.

## Event
* `EVENT_DUAL_BALANCE_CHECK`: 보상지급 전 듀얼 밸런스 조건 검증.
* `EVENT_POPUP_DISPLAY`: 친화적 대화 팝업 출력.

## Example
### 듀얼 밸런스 적용 팝업 멘트
> **정령과의 대화 팝업**:
> "오늘 물 1.5리터 마시기 달성! 💧 덕분에 정령 '플로라'의 기운이 맑아졌어요. 내일도 저와 함께 건강한 하루 만들어가요!"

## Exception
사용자가 단시간 내 이상 수치(예: 1시간 내 5만보 걸음 등)를 입력하여 밸런스를 파괴하려 할 경우 아래 예외 처리를 실행한다:

```json
{
  "exception": "ERR_DUAL_BALANCE_ABNORMAL_INPUT",
  "message": "갑작스러운 수치 변화가 감지되었습니다. 건강을 위해 적정한 리듬을 유지해 주세요!",
  "action": "CAP_APPLIED_AND_LOGGED"
}
```
