# 웹 앱 아이콘 채우기 안내

이 폴더에는 실제 PNG 아이콘 파일이 아직 없습니다 (텍스트 전용 작업 환경이라
바이너리 이미지 파일을 생성할 수 없었습니다). `manifest.json`이 아래 4개
파일을 참조하므로, 배포 전에 반드시 채워 넣어야 합니다.

## 필요한 파일

| 파일명 | 크기 | 용도 |
|---|---|---|
| `Icon-192.png` | 192x192 | 일반 아이콘 |
| `Icon-512.png` | 512x512 | 일반 아이콘 (고해상도) |
| `Icon-maskable-192.png` | 192x192 | 안드로이드 적응형 아이콘 (여백 포함) |
| `Icon-maskable-512.png` | 512x512 | 안드로이드 적응형 아이콘 (고해상도) |

또한 `web/` 폴더 바로 아래에 `favicon.png` (브라우저 탭 아이콘)도 필요합니다.

## 만드는 방법 (택 1)

1. **기존 `08_ASSETS/Logo` 또는 `06_DESIGN/Mascot` 폴더의 캐릭터/로고
   이미지**를 [https://www.pwabuilder.com/imageGenerator](https://www.pwabuilder.com/imageGenerator)
   같은 무료 도구에 올리면 필요한 모든 크기를 한 번에 생성해줍니다.
2. `flutter create .`를 프로젝트 루트에서 다시 실행하면 Flutter 기본
   아이콘으로라도 이 폴더가 자동 생성됩니다 (이후 실제 디자인으로 교체 권장).
3. maskable 아이콘은 사방에 안전 여백(전체 크기의 약 10~20%)을 두고
   중앙에 로고를 배치해야 안드로이드에서 잘리지 않습니다.

아이콘이 없어도 `flutter build web`은 정상적으로 실행되지만, 브라우저
"홈 화면에 추가" 시 기본 회색 아이콘이 표시됩니다.
