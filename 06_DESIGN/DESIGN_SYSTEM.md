# DESIGN SYSTEM

Version: 1.0

---

# Purpose

This document defines the visual, interaction, and accessibility principles of Guild Health.

The Design System ensures a consistent healthcare-first user experience across all platforms.

---

# Design Philosophy

Health First

Clarity Over Complexity

Encourage, Never Shame

Celebrate Progress

Consistency Across Screens

Accessibility by Default

# Color Principles

Primary colors should communicate trust and wellness.

Success colors celebrate achievements.

Warning colors should guide, not frighten.

Avoid aggressive or alarming visual language.

Health Score should use gradual color transitions instead of abrupt changes.

---

# Typography

Readable at all ages.

Support dynamic font scaling.

Maintain strong visual hierarchy.

Avoid decorative fonts for core health information.

# Motion

Animations should:

Support understanding.

Be subtle.

Never delay critical interactions.

Allow users to reduce motion.

---

# Accessibility

Support:

Screen Readers

Keyboard Navigation

High Contrast

Dynamic Text Size

Color-blind Friendly Indicators

Touch Target Minimum Size

---

# Empty States

Every empty state should encourage the next healthy action.

Never make the user feel guilty.

Example:

"No exercise recorded today."

Instead of:

"You failed today's goal."

---

# Error Messages

Errors should:

Explain the issue.

Suggest a solution.

Remain calm and supportive.

Never blame the user.

---

# Gamification Guidelines

Gamification is secondary.

Health information always has higher visual priority.

Rewards should reinforce healthy habits.

Never pressure users into unhealthy behavior.

---

# Future Expansion

Support:

Tablet Layout

Desktop Layout

Watch Interface

TV Dashboard

without redesigning the design language.
