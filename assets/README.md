# HEALTH IS ALL 에셋 보관함

이 폴더는 사용자가 제공하고 승인한 이미지의 원본과, 앱에 실제 쓰기 위해 정규화한 결과물을
보관한다. 대용량 이진 파일은 Git LFS로 GitHub에 보관한다.

- `source/`: 제출된 원본 및 참고 자료. 수정하지 않는다.
- `approved/hero-portraits/`: 승인된 용사 공식 초상 원본.
- `approved/combat-sprites/`: 배경 제거·프레임 분할·규격 검증이 끝난 전투용 결과물.
- `manifest/`: 출처, 승인 상태, 직업·성별·차수, 변환 이력을 기록한다.

화면 전체 시안은 참고 자료이며 런타임 화면으로 직접 사용하지 않는다. 텍스트, 수치, 버튼은
Flutter 위젯으로 구현한다.
