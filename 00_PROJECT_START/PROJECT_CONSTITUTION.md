# PROJECT CONSTITUTION

Version: 1.0

Guild Health is a commercial, long-term AI Healthcare + RPG habit platform.

## Non-Negotiable Principles

1. Clean Architecture
2. SOLID
3. Feature First Architecture
4. TypeScript Strict Mode
5. Reusable components
6. Production Ready implementation
7. Scalable structure
8. Maintainable code
9. Complete separation of UI and business logic
10. No hard-coding

Every capability is designed in this order:

Architecture → Folder Structure → Database → API → UI → Implementation

Healthcare First. Game systems exist only to support healthy, sustainable habits.
