# Stitch AI 최종 에셋 요청 목록

지금 당장 개발을 막는 이미지는 없다. 기능과 배치를 확정한 뒤 아래 순서대로 한 번에
제작한다. 모든 프롬프트에 `기존 상용 게임의 캐릭터·로고·UI를 복제하지 말 것`을 적용한다.

## 공통 아트 지시문

```text
HEALTH IS ALL : 건강이 전부다 !! 전용 오리지널 모바일 게임 에셋.
포근하고 흥미로운 SD 3D 판타지, 둥글고 읽기 쉬운 실루엣, 따뜻한 간접광,
풍부하지만 복잡하지 않은 화면 밀도. 영웅은 약 3.5~4.5등신, 정령은 2~3등신.
건강 앱의 흰색·민트 UI와 게임의 짙은 남색·황금색 세계를 명확히 분리.
특정 상용 게임의 캐릭터, 로고, 아이콘, UI 레이아웃을 복제하지 말 것.
이미지 안에 글자, 숫자, 로고를 넣지 말 것. 모바일 세로 화면 안전영역 확보.
```

## P0 — 실제 화면 연결 전에 필요한 4종

### 1. 홈 상단 게임 입장 배너

```text
[공통 아트 지시문]
가로 16:9 배너. 탱커, 전사, 마법사, 궁수, 도적, 치유사 여섯 영웅이
빛나는 탑을 향해 전진하는 장면. 왼쪽 또는 아래쪽에 UI 텍스트를 올릴 넓은 빈 공간.
배경은 짙은 남색에서 따뜻한 황금빛으로 이어지고, 파티 인원은 정확히 6명.
```

### 2. 게임 허브 자동 전투 배경

```text
[공통 아트 지시문]
세로 9:16. 여섯 영웅이 자연스러운 2열 진형으로 오른쪽 위의 적을 향해 자동 전진.
앞줄 탱커·전사, 중간 도적·치유사, 뒷줄 마법사·궁수의 역할이 실루엣으로 구분.
UI 버튼과 수치를 올릴 상단·하단 여백.
```

### 3. 용사 6인 투명 전신 세트

```text
[공통 아트 지시문]
탱커, 전사, 마법사, 궁수, 도적, 치유사 오리지널 영웅 6명.
같은 세계관과 비율, 각자 명확히 다른 실루엣과 대표 색. 정면 3/4 시점 전신,
중립 자세, 투명 배경, 캐릭터별 개별 PNG. 기본 전직 0단계 외형.
```

### 4. 360° 별자리 배경

```text
[공통 아트 지시문]
세로 9:16. 중앙 핵에서 바깥으로 7개 층이 회전하는 원형 별자리 성장판 배경.
각 층에는 대형 노드 자리 6개를 균등 배치하고 사이에는 다양한 소형·중형 노드 경로.
아이콘과 문자는 넣지 않고 UI가 노드를 덧씌울 수 있게 제작.
```

## P1 — 콘텐츠 구현 직전 필요한 4종

### 5. 정령 알·부화기·정령 6속성 세트

```text
[공통 아트 지시문]
불, 물, 바람, 숲, 빛, 달 속성의 알과 부화 완료 정령 각 1종.
랜덤 소환 포털이 아니라 따뜻한 연구실형 확정 부화기. 투명 배경 개별 PNG와
부화기 세로 화면 1장. 캡슐·룰렛·확률 표시는 금지.
```

### 6. 마을·길드 3D 디오라마

```text
[공통 아트 지시문]
세로 9:16, 작은 산중 마을의 3D 디오라마. 길드홀, 대장간, 작업실, 정령 부화실,
명예의 전당이 걸어서 연결. 건물은 과밀하지 않고 중앙 광장과 이동 동선이 명확.
평면 지도나 등각 2D가 아닌 실제 깊이감 있는 SD 3D 공간.
```

### 7. 층 보스 아레나 템플릿

```text
[공통 아트 지시문]
세로 9:16. 탑 한 층의 여섯 번째 방, 여섯 영웅과 거대한 오리지널 수호자 보스의 대치.
중앙 전투 영역과 상하단 HUD 안전영역 분리. 잔혹 표현 없이 긴장감 있는 판타지 조명.
```

### 8. 환생 연출 배경

```text
[공통 아트 지시문]
세로 9:16. 탑 층과 작은 별 노드는 빛으로 흩어지지만 여섯 영웅의 전직 실루엣과
여섯 개 대형 노드는 황금빛으로 남는 장면. 손실보다 새 회차의 기대감을 전달.
텍스트와 숫자 없이 전경·중경·배경을 분리하기 쉬운 구성.
```
