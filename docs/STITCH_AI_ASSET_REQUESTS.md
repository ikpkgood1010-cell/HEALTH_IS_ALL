이 파일은 작업 중 사용자에게 전달한 이미지 생성 프롬프트의 **영구 보관본**이다.
프롬프트는 작업 완료 보고에서도 생략하지 않으며, 새 요청이 생기면 이 파일에 누적한다.
제작된 에셋 역시 삭제하지 않고 `제작됨 / 검토 필요 / 수정 요청 / 적용 완료` 상태를 기록한다.

> 별자리 배경은 2026-08-14 최종 승인 및 앱 등록 완료. 아래 C·G·H·I 프롬프트는
> 제작 이력으로만 보존하며 같은 배경을 다시 생성하지 않는다.

지금 당장 개발을 막는 이미지는 없다. 기능과 배치를 확정한 뒤 아래 순서대로 한 번에
제작한다. 모든 프롬프트에 `기존 상용 게임의 캐릭터·로고·UI를 복제하지 말 것`을 적용한다.

## 앞으로 생성하는 모든 Stitch 프롬프트의 필수 조건

아래 조건은 캐릭터·몬스터·건물·배경 요청마다 용도에 맞게 **실제 문장으로 반복해서
삽입**한다. 사용자가 별도로 기억하거나 추가할 필요가 없어야 한다.

- 캐릭터 원화와 전투 스프라이트 중 어느 용도인지 명시
- 기준 이미지의 얼굴·머리·체형·대표색·직업 실루엣·무기를 재설계하지 않도록 명시
- 전신·무기·머리카락·발끝이 잘리지 않도록 사방 15% 안전 여백
- 흰 배경 제거용이면 `pure solid white #FFFFFF`, 바닥·그림자·배경·흰색 bloom 금지
- 흰 머리·흰 갑옷·투명 날개·마법광처럼 배경 제거에 취약한 부분은 어두운 외곽 분리색 사용
- 애니메이션용이면 오른쪽을 향하는 3/4 고정 시점, 동일 캔버스·바닥선·크기·카메라 고정
- 한 이미지에 한 캐릭터와 한 프레임만 생성하고 전체 sprite sheet를 한 번에 요청하지 않음
- 승인된 기준 프레임을 첨부한 strict image edit로 관절과 무기 위치만 변경
- 동작별 접지 발, 중심 이동, 타격 순간, 무기 궤적과 원위치 프레임을 구체적으로 지시
- 이미지 안의 글자·숫자·로고·UI·워터마크 금지
- 특정 상용 게임의 캐릭터·UI·로고·구도를 직접 복제하지 않음
- 결과 파일의 용도, 논리 캔버스, 프레임 번호, 방향을 파일명 규칙으로 지정

### A. 용사 6인 개별 투명 전신

아래 공통문 뒤에 직업별 지시문을 하나씩 붙여 **6장을 각각 따로 생성**한다.

```text
[출력 규격]
- 캐릭터 1명만 있는 세로형 전신 이미지 1장
- 권장 캔버스 2048×3072px 또는 가능한 최고 해상도, PNG
- 투명 배경, 바닥 그림자는 매우 옅은 반투명 형태
- 머리카락 끝, 무기 끝, 신발까지 잘리지 않게 사방 12% 안전 여백

- 카메라는 캐릭터 허리 높이, 원근 왜곡 최소화
- 기본 대기 자세, 양발이 모두 보이고 실루엣이 한눈에 읽혀야 함

[공통 조형]
- 3.8등신 SD 3D 캐릭터: 큰 머리, 짧지만 지나치게 유아적이지 않은 팔다리
- 포근하고 둥근 실루엣, 장난감 같은 고급 PBR 재질, 부드러운 모서리

- 따뜻한 좌측 상단 키라이트와 부드러운 우측 림라이트
- 모바일에서 120px 크기로 줄여도 직업이 구별되는 굵고 단순한 형태

- 특정 상용 게임의 캐릭터 얼굴, 복장, 무기, 로고, 색 배치를 복제하지 말 것
- 화면 안에 글자, 숫자, 직업명, 워터마크, UI 프레임을 넣지 말 것

[반드시 피할 요소]
2D 일러스트, 애니 셀 셰이딩, 실사 인물, 픽셀아트, 과도한 반사광, 검은 윤곽선,
```

### I. 별자리 최종 우회안 — 정사각형 좌우 아웃페인팅

```text

현재 이미지의 중앙 별, 석재 동심원 고리, 재질, 조명, 색상, 카메라 시점을 유지한다.

[가장 중요한 명령]

- 바깥 고리는 이미지의 위·아래·왼쪽·오른쪽 어느 가장자리에도 닿지 않음
- 고리 바깥으로 최소한 고리 두께 2배 이상의 우주 배경 여백

7개 고리 전체가 네 방향에서 완전히 보이고 바깥에 넓은 우주 여백이 있어야 한다.
```
