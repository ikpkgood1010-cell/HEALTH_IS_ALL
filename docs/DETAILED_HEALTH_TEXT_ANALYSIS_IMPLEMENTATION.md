# 상세 식단·운동 자연어 분석 구현

## 목적

사용자가 식단과 운동을 숫자 폼에 다시 옮기지 않고 평소 말하듯 기록해도, 저장 전에 계산 근거와 추정 범위를 확인하고 오늘 전체 리뷰에서 실제 보상까지 함께 볼 수 있게 한다.

## 사용자 흐름

1. 식단 또는 운동 탭에서 `기록하기`를 누른다.
2. 음식·수량·조리법·섭취 순서 또는 운동·시간·횟수·세트·휴식·RPE를 문장으로 쓴다.
3. 서버가 평균값과 범위를 계산한다.
4. `한 줌`, `1개`, 전체 운동시간처럼 결과에 영향을 주는 불명확한 값만 선택 카드로 확인한다.
5. 모든 필수 카드 확인 후 저장한다. 저장 응답에서 실제 Exp와 건강 정수를 확인한다.
6. 운동·식단 탭의 `오늘 전체 상세 리뷰`에서 하루 합계와 기록별 상세를 확인한다.

## 구현 범위

- API
  - `POST /api/v1/health/text/analyze`
  - `GET /api/v1/health/review/daily/{user_id}`
- 식단 분석
  - 음식별 평균 중량 및 최소·최대 추정 범위
  - 열량, 탄수화물, 단백질, 지방, 식이섬유
  - 식단점수, 식품 다양성, 섭취 간격, 조리 형태
  - 같은 날 `오늘 점심이랑 똑같이 먹었어` 참조 복사
- 운동 분석
  - 복합 운동을 운동 블록으로 분리
  - 총 운동시간, RPE, 활동점수, 세트간 휴식, 무휴식 전환
  - CrossFit Cindy 라운드를 턱걸이·푸시업·에어스쿼트 반복 수로 구조화
  - 계단 상승 층수와 엘리베이터 하강 구분
- 저장 및 리뷰
  - 분석 결과를 기존 활동 로그와 동일한 중복 방지 경로로 저장
  - 서버가 확정한 실제 Exp·건강 정수 표시
  - 하루 영양소 예상값과 추정 범위, 식사·운동별 상세 표시

## 계산 원칙과 출처

- 한국 식품은 농촌진흥청 국립식량과학원의 [국가표준식품성분 DB 10.4(2026)](https://www.nics.go.kr/food/kfi/fct/fctFoodSrch/list)를 우선 기준으로 한다.
- 국내 기준으로 식별하기 어려운 일반 식품과 제품 후보는 [USDA FoodData Central](https://fdc.nal.usda.gov/)의 100g당 평균값을 보조 기준으로 한다.
- 운동의 시간·횟수·세트·RPE는 사용자가 쓴 값과 확인한 값을 최우선으로 한다. 공중보건 리뷰 기준은 [WHO 신체활동 지침](https://www.who.int/publications/i/item/9789240014886)을 사용한다.
- 수면 리뷰를 연결할 때는 연령별 [CDC 수면 기준](https://www.cdc.gov/sleep/about/index.html)을 사용한다.
- 앱 화면에는 `ⓘ 계산 산출 기준`과 의료 진단이 아니라는 고지를 함께 표시한다.

## 안전 규칙

- 음식명을 하나도 식별하지 못하면 임의의 열량을 저장하지 않고 입력 보완 카드로 차단한다.
- 불명확한 가정은 단일값처럼 표시하지 않고 낮음·예상·높음 범위로 보존한다.
- 보상 미리보기는 참고값이며, 실제 보상은 서버의 일일 한도·중복 방지 규칙을 거친 저장 응답만 확정값으로 표시한다.
- 상세 원문과 계산 결과는 기존 `detail_json` 2,000바이트 제한 안에 들어오도록 축약 저장한다.
- 심박과 짧은 세트간 휴식은 운동 분석에 반영할 수 있지만 위험 행동을 유도하는 별도 보상으로 사용하지 않는다.

## 현재 식품 인식 범위와 다음 확장

MVP 내장 카탈로그는 사용자 예시 전체와 자주 쓰는 기본 식품 19종을 즉시 계산한다. 모든 시판 제품과 모든 세계 음식을 정밀하게 지원하려면 다음 단계에서 국가표준식품성분 DB/OpenAPI 및 제품 영양성분 검색 계층을 붙여야 한다. API 계약과 확인 카드 구조는 이 데이터 공급자를 교체하거나 확장해도 앱 화면을 바꾸지 않도록 분리했다.

제품명 검색 결과가 여러 개이면 다음 우선순위를 사용한다.

1. 정확한 제품명·중량이 일치하는 영양표
2. 동일 제조사·동일 제품군 평균
3. 국가표준식품성분표의 동일 조리 상태 일반 식품
4. USDA의 동일 식품·조리 상태 평균
5. 그래도 불명확하면 사용자가 선택하는 후보 카드

## 검증 사례

- 아침 `양배추 한 줌 ... 삶은 계란 3개`
- 점심 `햇반, 시금치, 마늘, 생강, 냉동표고, 산수유, 우엉, 닭가슴살, 생양파`
- 저녁 `오늘 점심이랑 똑같이 먹었어`
- 운동 `CrossFit Cindy 20분 18라운드 + 계단 + 케틀벨·웨이트 5세트`

백엔드 전체 테스트, 변경 Flutter 파일 정적 분석, 핵심 기록·내비게이션 Flutter 테스트로 검증한다.
