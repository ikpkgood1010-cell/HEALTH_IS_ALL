# HEALTH IS ALL 이미지 에셋 인입 검토 — 2026-08-18

## 결론

사용자가 제공한 22개 묶음에서 이미지 549개를 전수 확인했다. 같은 바이트의 중복 파일은 없었다.
새 방향인 **32-bit 소프트 청키 픽셀도트 UI + 6인 동시 자동전투**에 맞는 유효한 기반이 충분하다.

다만 생성된 전체 화면 시안은 앱 화면에 그대로 붙이는 이미지가 아니다. Flutter 위젯으로 재구성할
레이아웃·색상·프레임 참고 자료이며, 한국어 문구·숫자·버튼 라벨은 반드시 코드에서 표시한다.

## 바로 쓸 수 있는 것과 고칠 수 있는 것

### 바로 쓸 수 있는 후보

- 투명 PNG인 파트6 시스템 아이콘 32개
- 건강 UI·게임 UI 화면 시안의 색상, 프레임, 정보 우선순위
- 정령·알, 몬스터, 마을 건물의 콘셉트와 실루엣
- 실제 필드 위에 용사와 적이 배치된 전투 화면의 구도

### Codex가 후처리할 수 있는 범위

- 흰색 또는 한 가지 고정 색 배경 제거, 여백 자르기, 캔버스 크기 통일
- nearest-neighbor 확대, 파일명·직업·차수·ID 표준화, 스프라이트 시트 분할
- 색상 팔레트 검사, 배경/투명도/프레임 수/해상도 manifest 생성

### 원본을 다시 만들어야 하는 범위

- 서로 다른 화풍의 4–6차 용사 초상 통일
- 전투용 용사·몬스터의 대기/이동/공격/피격/사망 프레임
- 사각 매트가 남는 스킬 이펙트의 최종 투명 프레임 시트
- 완성 화면에 들어간 읽을 수 없는 AI 텍스트와 버튼 라벨
- 다중 레이어가 아닌 단일 완성 화면으로 만든 전투 배경

## 최종 제작 규격

1. **화면**: 배경·프레임·아이콘만 이미지로 사용하고, 텍스트·수치·버튼은 Flutter 위젯으로 표시한다.
2. **용사**: 12명 × 0–6차 = 84장의 공식 픽셀 초상은 모두 같은 4.8–5.2등신, 3/4뷰, 동일한 바닥선,
   동일한 외곽선 두께와 팔레트 밀도를 사용한다. 대형 노드를 열면 해당 직업의 남녀 전직 외형을 함께 얻는 규칙과 호환한다.
3. **전투 스프라이트**: 용사 승인이 끝난 뒤, 직업당 동일한 규격의 idle 3프레임·walk 4프레임·attack 4프레임·skill 6프레임·hit 2프레임·defeat 3프레임만 우선 만든다. 전투는 카드·덱·턴·제한시간 없이, 사거리에 따라 자리잡은 6명이 동시에 자동으로 전투한다.
4. **배경**: 전투 한 장소를 `far`, `mid`, `ground`, `foreground` 4개 레이어로 분리하고, 같은 전장 기준선·조명·팔레트를 유지한다. 글자는 배경에 넣지 않는다.
5. **효과**: 가능하면 투명 PNG(RGBA)로 받고, 불가능하면 외곽선에 쓰지 않는 단일 마젠타(`#FF00FF`) 매트 배경을 사용한다. 검정은 픽셀 외곽선에 쓰이므로 검정 배경을 chroma-key 대상으로 선택하지 않는다.
6. **원화 보관**: 대용량 원본 ZIP과 생성 중간본은 Git에 넣지 않는다. 로컬 원본 보관소와, 앱에서 실제 선택한 최적화본만 별도 manifest로 관리한다.

## 누락된 우선 에셋

1. 12명 0–6차 용사의 공식 ID/직업/성별/차수 표와 승인본 84장
2. 각 직업의 6종 핵심 동작 프레임 시트(용사 승인 후)
3. 각 몬스터의 정상/엘리트/보스별 전투 스프라이트와 피격 지점
4. 1개 시작 지역의 4레이어 전투 배경과 바닥 충돌선
5. 마을 전체 지도 1장과 건물의 기준 크기·입구 위치·탭 동선
6. 픽셀 UI 프레임, 버튼, 입력창, 진행바, 배지의 코드용 9-slice 규격
7. 실행 가능한 실제 텍스트·아이콘 매핑 및 접근성(고대비·글자 크기) 상태

## 다음 적용 순서

1. 용사 84장에 대해 직업·성별·차수·승인 여부를 확정한다.
2. 용사 승인본을 기준으로 전투 스프라이트 요청서를 만든다.
3. 건강 4탭과 게임 진입/내부 화면을 픽셀 UI 위젯으로 구현한다.
4. 선별된 이미지에만 후처리·압축·manifest를 적용해 앱에 넣는다.

전투 에셋을 용사 승인 뒤로 미룬 현재 순서는 적절하다. 아직 원화가 고정되지 않은 상태에서
공격 프레임을 만들면 전직별 장비와 실루엣이 바뀔 때 전부 다시 만들어야 하기 때문이다.
