# HEALTH IS ALL 게임 UI·아트 적용 기준

## 목표

건강 기록 화면의 명확성은 유지하되 게임 화면을 단순한 흰 카드 모음으로 만들지 않는다.
길드·모험·성장 화면은 사용자가 다음 장면을 보고 싶게 만드는 포근한 SD 3D 판타지로
구성한다. 특정 게임의 캐릭터·의상·아이콘·화면 배치를 복제하지 않고, 밝고 편안한
여행 감성과 읽기 쉬운 정보 밀도 원칙만 참고한다.

## 화면 구성

1. 화면 상단 35~45%에는 캐릭터 또는 장소가 중심인 대표 장면 하나를 둔다.
2. 핵심 상태와 행동은 장면 아래 2~3개의 묶음으로 제한한다.
3. 전투 장면은 중앙 캐릭터와 몬스터를 우선하고, 수치·버튼을 화면 가장자리에
   흩뿌리지 않는다.
4. 같은 중요도의 카드가 반복되는 대시보드 표현을 피하고, 장면·진행·보상 순서의
   시각적 위계를 만든다.
5. 건강 수치와 기록 버튼은 장식보다 높은 대비와 최소 44px 터치 영역을 유지한다.

## 색과 형태

- 기본색: 크림, 따뜻한 숲색, 맑은 하늘색
- 강조색: 금빛 노랑, 산호색, 생기 있는 민트
- 위험 안내: 공격적인 빨강 대신 충분한 대비의 따뜻한 주황을 우선하되 실제 건강
  위험 경고는 접근성 기준에 맞는 빨강을 사용한다.
- 캐릭터: 약 2.5~3등신, 큰 머리와 손, 멀리서도 구분되는 단순한 실루엣
- 패널: 두꺼운 둥근 모서리, 약한 깊이감, 배경 장면과 구분되는 반투명 또는
  양피지 계열 표면

## 정보 밀도

- 화면당 가장 중요한 시각 초점은 하나만 둔다.
- 한 패널의 주요 행동은 최대 1개, 화면 전체의 강한 행동은 최대 3개다.
- 장면 배경은 텍스트가 놓이는 영역에서 채도와 대비를 낮춘다.
- 장식 아이콘은 정보를 대신하지 않으며 텍스트 라벨과 함께 사용한다.

## 이미지 제작 규격

### 캐릭터 컷아웃

- 1024×1024 PNG, 투명 배경
- 전신 3/4 정면, 중앙 정렬, 사방 안전 여백 12% 이상
- 부드러운 3D 재질과 따뜻한 주광, 과도한 외곽선 금지
- 텍스트·UI·로고·배경을 이미지에 포함하지 않는다.

### 대표 장면

- 1536×864 WebP 또는 PNG
- 주요 인물은 중앙 또는 오른쪽 1/3에 두고 왼쪽 하단에 UI 안전 영역을 남긴다.
- 글자와 버튼을 이미지에 합성하지 않는다.
- 모바일 세로 크롭에서도 캐릭터와 핵심 장소가 남도록 중앙 안전 영역을 지킨다.

## 건강 우선 안전 규칙

- 활동이 적은 날 캐릭터가 아프거나 실망한 표정을 짓게 하지 않는다.
- 과도한 운동을 전투력·희귀 보상과 직접 연결하지 않는다.
- 휴식과 회복도 모험의 긍정적인 결과로 표현한다.
- 유료 뽑기처럼 보이는 연출과 희귀도 확률 표시는 사용하지 않는다.
