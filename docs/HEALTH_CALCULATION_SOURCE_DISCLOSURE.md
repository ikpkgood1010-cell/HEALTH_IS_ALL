# 건강 계산 산출 기준 표시 원칙

상태: **APPROVED DIRECTION / 2026-08-16**

건강 화면의 작은 `!` 또는 `ⓘ` 버튼에서 계산 근거와 한계를 확인할 수 있게 한다. 출처
이름만 작게 나열하지 않고, 누르면 어떤 기록에 어떤 기준을 사용했는지 보여 준다.

## 짧은 화면 문구

```text
ⓘ 계산 기준
활동·수면·식단 점수는 사용자가 확인한 기록과 공신력 있는 공개 기준을 참고한
웰니스용 추정치입니다. 의료 진단이나 치료 기준이 아닙니다.
```

## 상세 화면에 표시할 출처

- 신체활동: WHO Guidelines on Physical Activity and Sedentary Behaviour
- 수면: 미국 CDC 연령별 수면 권고
- 한국 식품: 농촌진흥청 국가표준식품성분표
- 보조 식품 데이터: USDA FoodData Central
- 저항운동 일반 원칙: American College of Sports Medicine 지침
- Android 건강 연동 형식: Android Health Connect 공식 문서

각 출처에는 문서명, 기관, 확인일, 링크를 표시한다. 앱의 자체 점수 가중치와 게임 재화
변환식은 외부 기관이 승인한 수식처럼 표현하지 않고 `HEALTH IS ALL 자체 게임 산식`으로
별도 공개한다.

## 금지 표현

- `WHO 인증 점수`, `CDC가 승인한 계산식`
- `정상`, `비정상`, `운동 가능`, `완전 회복`
- AI 사진 분석 칼로리를 확정값으로 표시
- 출처를 근거로 개인의 질환·위험도·치료 필요성을 자동 판정

출처 표시는 신뢰를 높이는 장치이지만, 외부 지침의 존재가 앱 자체 가중치의 의학적 검증을
의미하지 않는다는 한계를 함께 보여 줘야 한다.
