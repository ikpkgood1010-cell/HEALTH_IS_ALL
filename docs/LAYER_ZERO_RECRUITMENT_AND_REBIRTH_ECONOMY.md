# 0계층 영입·회차 성장·30회 환생 경제

상태: **CODE COMPLETE / BALANCE CANDIDATE / DATABASE NOT APPLIED / 2026-08-14**

## 최신 확정안 적용

게임 기획 대화에는 초안과 수정안이 함께 있어 다음 충돌을 시간순으로 정리했다.

| 과거 초안 | 현재 적용 기준 |
|---|---|
| 0계층 대형 노드 6개 | 무료 첫 용사를 제외한 영입 노드 5개 |
| 랜덤 정령 또는 랜덤 영입 | 영입·정령 모두 확정, 중복 없음 |
| 고강도 운동량에 비례한 폭발적 재화 | 개인 목표 100% 상한과 비처벌 원칙 |
| 환생 시 용사 재영입 | 영입·대형 노드·전직 영구 보존 |
| 건강 기록을 게임 노드에 표시 | 원본 건강 기록은 건강 앱에만 표시 |

## 0계층 경로

첫 용사 1명은 무료 선택한다. 선택하지 않은 5명의 용사는 각자 다음 경로를 가진다.

```text
소형 1 → 소형 2 → 소형 3 → 중형 1
       → 소형 4 → 소형 5 → 소형 6 → 중형 2
       → 대형 노드에서 해당 용사 확정 영입
```

- 소형·중형 노드는 회차 골드로 해금하며 환생 시 초기화된다.
- 소형 노드 하나는 이번 회차 파티 전투력 +2%, 중형 노드는 +5% 후보다.
- 한 경로를 모두 열면 전투력 후보 보너스는 +22%다.
- 대형 영입 노드는 추가 비용이나 랜덤 선택 없이 해당 용사를 확정 영입한다.
- 영입과 대형 노드는 환생 후 영구 보존된다.
- 이미 영입한 용사의 소형·중형 경로도 다음 회차에 다시 열어 회차 전투력을 높일 수 있다.

## 골드 후보 수식

`backend/constellation_economy.py`의 상수 한 곳에서만 조정한다.

```text
기본 비용 = 1,500 골드
깊이별 비용 = ceil10(1,500 × 1.15^(순번-1) × 등급 배율)
소형 배율 = 1
중형 배율 = 3
```

이 수식은 과거 기획의 `C(N) = Base × 1.15^(N-1)`와 소형 1배·중형 3배 구조를
사용하되, 당시 예시의 운동 포인트를 현재 canonical 회차 골드로 치환한 후보다. 건강
정수와 별 조각의 소비처가 확정되기 전에 사용자의 건강 성취 재화를 임의 차감하지 않는다.

## 안전한 해금

`POST /api/v1/game/constellation/unlock`

- 현재 revision과 정확히 다음 노드만 허용한다.
- 경로를 건너뛰거나 다른 사용자의 상태를 수정할 수 없다.
- 골드가 부족하면 아무 변화 없이 HTTP 409로 끝난다.
- 이미 성공한 같은 `node_code` 재요청은 골드를 다시 빼지 않고 현재 상태를 반환한다.
- 대형 노드 영입도 한 번만 저장된다.

## 자율 환생 후보

- 최소 100층부터 사용자가 원하는 시점에 환생할 수 있다.
- 환생 보상 별 조각 후보는 `floor((현재 층 / 100)^0.75)`, 최소 1개다.
- 100층 미만에서는 별 조각이 없으며 환생도 차단한다.
- 골드·현재 층/방·소형/중형 노드·현재 방 경과시간은 초기화한다.
- 영입 용사·전직·대형 노드·건강 정수·기존 별 조각은 보존한다.
- 새 별 조각 지급량은 환생 감사 로그에 기록한다.

## 30회 환생 결정론적 시뮬레이션

명령: `python scripts/simulate_rebirth_economy.py`

15분마다 전투를 정산하고, 미영입 용사 경로를 먼저 완성한 뒤 영입 완료 경로를 회차
성장에 사용하는 자동 전략으로 계산했다.

| 결과 | 후보값 |
|---|---:|
| 첫 회차 | 22시간, 100층, 용사 4명 |
| 6인 파티 완성 | 2회차, 누적 약 40.5시간 |
| 이후 환생 1회 평균 | 약 17.25시간 |
| 30회 총시간 | 523.5시간 |
| 일반 회차 해금 노드 | 27/40개 |
| 환생 직전 남는 골드 | 약 5,045 |
| 30회 뒤 별 조각 | 30개 |

판정:

- 6인 완성은 게임의 끝이 아니라 약 이틀 뒤 열리는 본 게임 시작점이다.
- 회차마다 골드 소비처가 다시 생겨 골드가 무한 누적되지 않는다.
- 노드 40개를 매 회차 모두 살 수 없으므로 사용 경로 선택과 이후 영구 성장의 여지가 남는다.
- 별 조각은 100층 반복에서 회차당 1개로 선형 누적되어 초기 폭증이 없다.
- 전직 경로·초월 소비처·건강 정수 어댑터가 연결되면 같은 스크립트를 확장해 다시 조정한다.

## UI와 에셋

Flutter 별자리 화면에 용사별 진행도, 소형/중형 개수, 사용 골드, 다음 노드 비용, 확정
영입 버튼을 연결했다. 노드·선·상태는 정확성이 필요한 동적 UI이므로 승인된 별자리
배경 위에 Flutter가 그린다. 이번 작업에는 새 래스터 이미지가 필요하지 않으며 Stitch AI
프롬프트를 추가하지 않는다.
