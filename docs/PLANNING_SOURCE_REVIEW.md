# HEALTH IS ALL 기획 자료 검토 기록

## 현재 우선순위

1. 사용자가 직접 확정한 최신 결정
2. 새 게임 기획 대화 1→2→4→5→6→7→8과 동봉 프롬프트
3. Master Prompt V10→V1 및 TODO LIST
4. 개발기획 1~42 합본과 Claude 검토
5. 타 게임 개발기획서와 Spec 자료
6. UI·Stitch 이미지는 확정 기획이 아니라 표현 참고

최신 자료가 기존 구조를 전면 변경했으므로 과거 문서의 5탭·길드 중심·12시간 자동
모험은 canonical이 아니다. 상세 충돌 판정은 `GAME_PLANNING_CONFLICT_RESOLUTION.md`,
현재 기준은 `GAME_DIRECTION_V2_CANONICAL.md`를 따른다.

## 변하지 않은 건강 기준

- 건강 기록과 회복이 서비스의 최우선 가치다.
- 익명 MVP를 유지하며 계정 이전 정책 전에는 소셜 로그인을 노출하지 않는다.
- HBI는 `최저 영역 60% + 전체 평균 40%`다.
- 활동 종류·강도·시간을 분리하고 다양한 운동을 개인 목표 기준으로 정규화한다.
- 활동이 적은 날, 질병, 회복일을 처벌하지 않는다.
- 게임은 건강 원본 기록을 직접 저장·표시하지 않고 파생 보정치만 사용한다.

## 새로 우선 적용한 게임 기준

- 건강 하단 4탭과 홈 상단 게임 입장
- 게임 내부의 6인 완전 자동 전투·마을·길드·별자리·정령·제작·환생
- 시작 시 첫 용사 1명 무료 선택. 0계층은 나머지 5명의 영입 노드, 1~6계층은 각 6명의 전직 노드
- 랜덤·중복 없는 정령 확정 부화와 스킬·아바타 확정 제작
- 전직 영구 보존, 소형·중형 노드만 환생 초기화
- 별도 장비 인벤토리와 가챠 없음
