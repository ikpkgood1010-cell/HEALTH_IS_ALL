# 새 게임 에셋 감사

검토 원본: `1~8까지의 에셋 일부 생성.zip`

총 672개 항목을 확인했으며 PNG 297개, HTML 59개, Markdown 16개와 폴더 300개로
구성돼 있다. 기능·배치를 먼저 확정하고 마지막 아트 적용 단계에서 정리한다.

## 등급

- `REFERENCE`: 구도·분위기 참고 가능, 제작 원본으로 바로 사용하지 않음
- `REGENERATE`: 방향은 맞지만 확정 규칙에 맞춰 다시 생성 필요
- `REJECT`: 최신 기획과 충돌해 사용 금지

| 대표 자료 | 등급 | 판단 |
|---|---|---|
| 홈 4탭+상단 게임 카드 | REFERENCE | 최신 정보구조와 일치, 텍스트·아이콘 재제작 |
| 6인 전진 파티 | REFERENCE | 파티 수·온기·전진감 적합, 직군 실루엣 보정 필요 |
| 360° 별자리 | REFERENCE | 어두운 배경과 원형 노드 구조 적합 |
| 보스 아레나 | REFERENCE | 층의 여섯 번째 방 참고 |
| 명예의 전당 | REFERENCE | 개인 누적 성과 공간에 적합 |
| 5인 길드하우스 | REGENERATE | 6인 고정과 충돌 |
| 평면 2D 마을 지도 | REGENERATE | 동선만 참고하고 3D 디오라마로 변경 |
| 납작한 정령 아이콘 세트 | REGENERATE | 속성 구분 참고, SD 3D 볼륨 필요 |
| 가챠 포털/랜덤 소환 | REJECT | 확정 부화와 충돌 |
| 하단 길드 포함 5탭 UI | REJECT | 확정 4탭과 충돌 |

## 저작·브랜드 안전

- 특정 상용 게임의 캐릭터, UI, 아이콘, 명칭, 화면 구성을 그대로 복제하지 않는다.
- `고고머핀 스타일`은 포근한 SD 3D, 따뜻한 조명, 흥미롭지만 정돈된 밀도라는
  분위기 참고어로만 사용한다.
- Stitch 산출물은 글자 깨짐, 손가락/무기 오류, 파티 인원, 직군 구분, UI 안전영역,
  투명 배경 여부를 확인한 뒤 저장소에 넣는다.
- 이번 구현에는 AI 생성 이미지를 직접 포함하지 않았다. 현재 화면은 기능·배치 검증용이다.
