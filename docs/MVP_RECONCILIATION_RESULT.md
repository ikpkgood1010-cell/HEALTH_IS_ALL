# 익명 MVP 기획 정합화 결과

## 반영 완료

- 확정 하단 탭을 `홈 / 운동 / 식단 / 길드 / 마이` 5개로 통일했다.
- 익명 MVP를 유지하고 이름·이메일·로그아웃 중심의 계정 화면을 제거했다.
- 토스형 민트 디자인 시스템과 건강 중심 홈·운동·식단 기록 흐름을 연결했다.
- 마스터 프롬프트의 HBI 공식과 비처벌 보상 원칙을 백엔드와 Flutter에 동일하게 반영했다.
- 운동 27종 분류, 강도·RPE·컨디션 입력, 근육 회복 계산 API를 구현했다.
- 건강 기반 길드·탑·환경 미리보기를 구현했다.
- 자동 모험을 12시간 단위·70% 효율로 서버에 저장하고 중복 수령을 차단했다.
- 길드 주화 보상의 20%가 자동 투자되는 훈련장 1종을 구현했다.
- 게임 이벤트가 건강 연속 기록을 올리지 않도록 분리했다.

## 의도적으로 보류

- 실제 결제, 확률형 뽑기, 광고, 유료 재화
- 계정 로그인과 익명 데이터 이전
- 기억 조각 실제 지급·환생 실행
- 상점·거래·길드 경쟁처럼 경제 검증이 먼저 필요한 기능
- 확정 자료가 없는 신규 캐릭터·일러스트의 임의 제작

## 검증 범위

- Python API·게임 로직 전체 테스트
- Flutter 프로젝트·위젯 전체 테스트
- 정적 분석, 문서·상수 무결성 검사, Web production build
- 로컬 웹 구동 및 주요 화면 수동 확인
- 실제 Supabase 데이터나 운영 migration은 변경하지 않음

## 다음 권장 묶음

다음 개발은 PR을 자잘하게 나누지 않고 `건강 기록 → 실제 모험 콘텐츠 → 길드 성장 피드백`의 한 사용자 여정으로 묶는다. 실제 운영 데이터 변경이나 경제·결제처럼 되돌리기 어려운 결정만 사용자 승인을 받는다.
