# 익명 MVP 기획 정합화 결과

## 변경한 것

- 하단 내비게이션을 확정된 `홈 / 운동 / 식단 / 길드 / 마이` 5개로 통일했다.
- 기존 깨진 한글과 임시 3탭 테스트를 제거했다.
- 홈을 건강 균형·운동·식단·수분·꾸준함 중심의 토스형 카드 UI로 정리했다.
- 운동과 식단을 독립 탭으로 연결했다.
- 가짜 이름·이메일·로그아웃을 제거하고 익명 MVP 마이 화면으로 바꿨다.
- HBI와 게임 재화 예상치를 프런트엔드와 백엔드에서 같은 규칙으로 계산한다.
- 길드 탭에 건강 기록으로 변하는 환경·단계·탑·재화의 읽기 전용 미리보기를 추가했다.
- 활동이 없는 날에도 보상 배율이 1.0 아래로 떨어지지 않도록 했다.
- 던전 가중치와 첫 방/보스/보스 전 휴식 안전 규칙을 자동 테스트에 추가했다.
- 추가 Spec 자료의 운동 27종 Enum, 대분류·강도 분리, RPE·컨디션 입력을 반영했다.
- 강도·컨디션·빈도·연령 계수를 사용하는 근육별 회복 계산 API를 추가했다.

## 의도적으로 하지 않은 것

- 실제 결제, 확률형 뽑기, 광고, 유료 재화
- 건강 기록을 초기화하거나 실제 기억 조각을 지급하는 환생 실행
- DB 스키마 변경과 migration 실행
- 확정 자료가 없는 게임 캐릭터·일러스트의 임의 제작
- 농장·낚시·집·보스·협동 길드 전체 기능을 완성한 것처럼 표시하는 행위

## 후속 권장 묶음

다음 개발은 작은 문서 WP를 반복하지 않고 `게임 MVP 세로 단면` 하나로 묶는다.
범위는 자동 모험 결과 저장, 중복 보상 방지, 길드 시설 1종 성장, 실제 API 연결,
통합 테스트까지다. 실제 재화 지급이나 데이터 초기화가 생기는 순간에만 사용자 승인을
받는다.
