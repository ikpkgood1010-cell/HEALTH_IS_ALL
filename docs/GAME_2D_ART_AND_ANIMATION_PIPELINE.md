# 2D 자동 전투 그래픽 제작 기준

상태: **CANONICAL / 2026-08-16**

## 1. 최종 표현 방식

- 캐릭터 선택·상세·도감·전직 연출: Stitch 고화질 공식 원화
- 마을·이동·전투: HD 픽셀아트 2D 스프라이트
- 전투 카메라: 오른쪽을 향하는 3/4 고정 시점
- 배경: 전경·중경·후경 2~3개 레이어의 시차 이동
- 전투 이동: 좌표 보간으로 접근하고, 사거리에서 멈춘 뒤 공격 동작 재생
- 실시간 3D 모델, Blender 모델링·리깅, 자유 회전 카메라는 사용하지 않는다.

## 2. 용사 제작 수량

- 고화질 외형 원화: 6직업 × 7차수 × 남녀 = 84장
- 게임 전직 해금 단위: 6직업 × 7차수 = 42개
- 하나의 전직 해금으로 같은 직업·차수의 남녀 외형을 동시에 획득한다.
- 남녀 외형에는 전투 성능 차이가 없고 출전 전 무료로 선택한다.
- MVP에 직업 6개를 더 추가하지 않는다. 신규 직업은 출시 이후 확장 후보로 둔다.

## 3. MVP 프레임 예산

| 동작 | 프레임 | 필수 키 포즈 |
|---|---:|---|
| 대기 | 3 | 기본·호흡 상승·복귀 |
| 이동 | 4 | 접지·교차·반대 접지·복귀 |
| 기본 공격 | 4 | 준비·휘두름·타격·복귀 |
| 액티브 스킬 | 6 | 준비·축적·발동·타격·후속·복귀 |
| 피격 | 2 | 충격·복귀 |
| 승리 | 3 | 반응·강조·유지 |
| 쓰러짐 | 3 | 균형 상실·낙하·정지 |

84개 외형 전체를 처음부터 애니메이션화하지 않는다. 먼저 0차 남녀 12명 중 한 직업
남녀로 전체 파이프라인을 검증하고, 0차 12명, 이후 1~6차 순서로 확장한다.

## 4. 파일 규격

- 캐릭터 논리 캔버스: 128×128px 권장
- AI 생성 검수본: 가능한 고해상도로 받은 뒤 nearest-neighbor 방식으로 축소
- 런타임: 투명 PNG 또는 무손실 WebP
- 기준 방향: 오른쪽. 왼쪽 방향은 런타임 반전이 가능한지 먼저 검증한다.
- 기준점: 발 중앙 하단을 모든 프레임에서 동일하게 유지
- 파일명: `hero_{class}_{gender}_t{tier}_{action}_{frame:02}_{direction}.png`

예: `hero_tanker_f_t0_attack_03_right.png`

## 5. 배경 제거 입력 조건

흰 배경 원본은 로컬에서 투명 배경으로 처리할 수 있지만 다음 조건을 만족해야 한다.

- 완전한 `#FFFFFF` 단색 배경
- 바닥, 그림자, 반사, 배경 소품 없음
- 캐릭터 윤곽과 맞닿는 흰색 bloom·안개·반투명 재질 없음
- 사방 15% 여백과 잘리지 않은 전신·무기
- 흰 머리·갑옷은 배경과 분리되는 회색·색상 외곽과 명확한 경계 사용

배경 제거는 가려진 팔·다리·장비 뒷면을 생성하지 않는다. 움직임 제작에 필요한 신체와
장비 형태는 원본에서 모두 분리되어 보여야 한다.

## 6. 장비와 치장 분리 기준

- 전직 기본 장비: 차수별 완성 외형에 포함한다.
- MVP 스킨·의상: 조합식 부품보다 완성 외형 교체를 우선한다.
- 별도 레이어 허용: 무기, 방패, 날개, 망토, 오라처럼 움직임이나 교체 가치가 큰 요소
- 머리색 등 단순 색상: 코드 색상 변환 가능 여부를 먼저 검증한다.
- 자유 조합형 머리·상의·하의·장갑·신발은 MVP 이후로 둔다.

분리 제작이 필요한 경우 맨몸이 아니라 중립적인 몸에 붙는 기본 내의를 사용한다. 모든
부품은 동일한 캔버스, 중심, 축척, 관절 위치를 유지해야 하며 독립 재생성하지 않는다.

## 7. Stitch 요청 작성 규칙

Codex가 사용자에게 Stitch 프롬프트를 줄 때마다 다음 항목을 생략 없이 프롬프트 본문에
직접 넣는다.

1. 프로젝트명과 실제 사용 화면
2. 첨부 기준 이미지에서 잠가야 할 얼굴·체형·색·장비
3. 원화 또는 전투 프레임이라는 자산 종류
4. 정확한 시점·방향·캔버스·바닥선·안전 여백
5. 흰 배경 제거 조건 또는 투명 배경 조건
6. 동작의 시작·최대 동작·타격·복귀 자세
7. 움직이면 안 되는 부위와 바뀌면 안 되는 디자인
8. 잘림·여분의 팔다리·무기 변형·텍스트 등 금지 항목
9. 파일명과 프레임 번호
10. 특정 상용 게임을 직접 복제하지 않는 독창성 조건

`[공통 지시문을 붙이세요]`처럼 사용자에게 조립을 맡기지 않고, 매번 바로 복사할 수 있는
완성형 프롬프트를 제공한다.

## 8. 제작·검수 순서

1. 직업별 고화질 공식 원화 승인
2. 같은 원화로 오른쪽 3/4 대기 기준 프레임 1장 생성
3. 얼굴·체형·무기·색·여백·접지점 검수
4. 기준 프레임 strict edit로 동작별 프레임을 한 장씩 생성
5. 흰 배경 제거와 투명 PNG 변환
6. 프레임 크기·바닥선·윤곽 흔들림 정렬
7. 앱에서 실제 속도로 반복 재생해 떨림·미끄러짐 검수
8. 한 직업 남녀가 통과한 뒤 나머지 직업과 차수로 확장
