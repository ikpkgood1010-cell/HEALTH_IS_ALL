# 게임 확장 밸런스 기준

## 1. 기본 원칙

`건강 행동 → 게임 자원 → 자동 모험과 공간 성장 → 다음 건강 행동의 긍정적 피드백`
순환을 사용한다. 앱 실행 횟수나 반복 클릭 자체에는 보상을 주지 않는다.

## 2. HBI

```text
HBI = min(운동, 식단, 수면, 스트레스) × 0.6
    + average(운동, 식단, 수면, 스트레스) × 0.4
```

각 영역은 0~100으로 제한한다. 현재 MVP에 수면·스트레스 연동이 없으므로 수분과
꾸준함을 화면에 명시한 대체값으로 사용하고 신뢰도를 `PARTIAL`로 표시한다. 실제
수면·HRV/RHR 연동 후 대체값을 제거한다.

낮은 HBI는 벌점이 아니다. 보상 배율의 최솟값은 항상 `1.0`이며 이미 얻은 자원,
연속 기록, 건강 기록을 회수하지 않는다.

## 3. 재화와 순환

| 재화 | 획득 | 사용 | 제한 |
|---|---|---|---|
| 활력 | 운동·식단·수분·꾸준함 | 자동 모험의 진행량 | 하루 계산 상한 200 |
| 길드 주화 | 활력을 자동 모험에서 전환 | 시설 성장·꾸미기·제작 | 유료 구매 없음 |
| 기억 조각 | 탑 30층 이후 순환 예상 보상 | 영구 해금·회상·장식 | 실제 지급은 순환 구현 전 비활성 |

유료 재화와 확률형 뽑기는 구성하지 않는다. 영웅과 정령은 스테이지·퀘스트·이벤트
구조에서 합류한다.

## 4. 던전과 자동 진행

- 일반 방 가중치: 전투 50 / 이벤트 15 / 휴식 15 / 상점 10 / 정예 10
- 첫 방은 전투, 마지막 방은 보스
- 보스 직전은 휴식 또는 상점
- 오프라인 누적 상한: 12시간
- 오프라인 효율: 온라인 기준 70%
- 보상 수령 전 결과는 한 번만 저장하고 반복 수령을 막는다.

## 5. 기억의 순환

- 최소 조건: 탑 30층
- 재사용 대기시간: 7일
- 초기화 대상: 탑의 임시 진행과 해당 회차의 임시 강화
- 보존 대상: 모든 건강 기록, 계정/익명 ID, 길드 시설, 수집품, 꾸미기,
  업적, 접근성 설정
- 기억 조각 예상식:

```text
floor(sqrt(도달 층) × 10 × (0.8 + HBI / 500))
```

실제 지급은 서버 저장·중복 방지·복구 테스트가 끝난 뒤에만 활성화한다.

## 6. 길드 성장 단계

| 레벨 | 단계 |
|---:|---|
| 1 | 작은 캠프 |
| 10 | 견습 길드 |
| 30 | 모험가 길드 |
| 50 | 유명 길드 |
| 100 | 전설 길드 |

## 7. 장기 확장 순서

1. 건강 기록 기반 자동 모험 결과 저장
2. 살아있는 길드 시설과 시각적 성장
3. 영웅 구조·제작·이벤트 방
4. 농장·낚시·집 꾸미기
5. 보스·협동 길드·모험 회상
6. 기억의 순환·기억의 길·명예의 전당

각 단계는 건강 기록을 강요하거나 앱 체류 시간을 인위적으로 늘리지 않는지 별도로
검증한다.
