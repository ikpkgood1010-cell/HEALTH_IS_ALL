# 게임 확장·밸런스 기준 V2

이 문서는 `GAME_DIRECTION_V2_CANONICAL.md`의 수치화 원칙을 보충한다. 과거
12시간·70% 자동 모험, 길드 주화 20% 자동 투자, 아루 영입 규칙은 폐기됐다.

## 고정 규칙

- 6인 파티, 층당 일반방 5개+보스방 1개
- 0~6계층 별자리. 0계층은 무료 선택 용사를 제외한 영입 노드 5개, 1~6계층은 전직 노드 6개
- 대형 노드·영입·전직은 영구, 소형·중형 노드는 회차용
- 영웅·정령·스킬·아바타 확률형 획득 금지
- 별도 장비 파밍·장비 인벤토리 없음

## 건강 보상 안전선

- 각 영역은 개인 목표 대비 0~100점으로 정규화한다.
- 목표 초과 운동량에 선형 보상을 주지 않는다.
- 가장 낮은 영역을 60%, 전체 평균을 40% 반영해 균형을 우선한다.
- 질병·휴식·회복일에는 손실이나 연속 기록 파괴를 적용하지 않는다.
- 구체적인 재화 숫자는 최소 30회차 시뮬레이션에서 막힘, 과잉 성장, 환생 체류시간을
  비교한 뒤 운영표로 승격한다.

## 경제 순환 초안

```text
건강 목표 달성 → 건강 정수/안전 보정치
자동 전투 → 골드와 회차 성장
골드 → 소형·중형 노드
대형 노드 → 영입·전직의 영구 성장
환생 → 회차 노드 초기화 + 별 조각/초월의 장기 성장
확정 제작 → 스킬·아바타 수집
```

골드는 회차 안에서 생성·소비·초기화된다. 건강 정수, 별 조각, 초월 특성은 영구
성장에 사용하되 일일 상한과 지출처를 함께 설계해 무한 누적을 막는다.
