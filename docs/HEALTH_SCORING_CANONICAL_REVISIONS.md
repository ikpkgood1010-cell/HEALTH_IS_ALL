# 건강·운동·식단·AI 계산 canonical 수정 기준

상태: **APPROVED / CODE NOT YET RECONCILED / 2026-08-16**

이 문서는 기존 건강 계산 초안에서 채택된 방향과 구현 전 반드시 수정할 항목을 고정한다.
게임 밸런스용 지표이며 의료 진단·치료·운동 가능 여부 판정식이 아니다.

## 1. 건강점수와 재화 분리

```text
표시용 건강점수 = 0.35×활동 + 0.20×수면 + 0.15×수분 + 0.15×식단 + 0.15×회복
```

- 각 항목은 0~100의 기록 지표다.
- 미기록은 0점이 아니라 `기록 없음`이다. 종합점수에는 데이터 범위를 함께 표시한다.
- 건강점수는 소비하지 않는다.
- 건강 정수는 확인된 건강 행동에서 일일 상한 안으로 얻고 전직에 소비하는 영구 재화다.
- 전직 대형 노드는 건강 정수와 별의 파편을 사용한다.

## 2. 기록 출처 공정성

- 필수 항목을 갖추고 사용자가 확정한 수동 기록: 기본 보상 100%
- AI 추출 후 사용자가 확정한 기록: 기본 보상 100%
- Health Connect 등 자동 연동: 기본 보상 100%, 중복 제거와 입력 편의에 사용
- AI 미확정 기록: 임시 표시만 하고 보상하지 않음
- 인증 기기 유무로 기본 보상 차이를 만들지 않는다.

AI가 만든 confidence 숫자는 실제 정확도 확률이나 건강·보상 승수로 해석하지 않는다.
낮음·보통·높음의 검토 우선순위와 `needs_confirmation` 결정에만 사용하며, 출시 전 검증
데이터셋으로 임계값을 조정한다.

## 3. 운동 기록

- 종목별 저·중·고강도는 입력 편의를 위한 초깃값이다.
- RPE가 있으면 사용자 RPE를 우선하고, 시간·세트·횟수·거리 등 실제 입력을 함께 저장한다.
- 중량 볼륨은 같은 동작의 개인 추세에만 사용하며 서로 다른 운동의 건강 효과를 비교하지 않는다.
- 목표 100% 이후 보상은 상한 또는 급격한 체감 감소를 적용한다.

### 운동 중 휴식·심박

- `짧을수록 좋음`, `심박이 높을수록 좋음` 형태의 단조 증가 보상은 사용하지 않는다.
- 세트 간 휴식은 사용자가 선택한 계획 또는 검수된 운동 템플릿의 범위 준수를 반영한다.
- 권장 범위보다 짧게 쉬어도 보상은 더 증가하지 않는다.
- 심박은 세션 구간의 유효 샘플 존재와 기록 완결성을 확인하는 데 사용한다.
- 휴식·심박 추가 보상 합계는 세션 기본 보상의 최대 5%이며 별도 일일 상한을 둔다.

## 4. 수면·수분·회복

- 수면은 `수면 기록 달성도`로 표시하고 건강한 수면을 인증한다고 표현하지 않는다.
- 취침·기상 시각 차이는 자정을 넘는 순환 시간 차이로 계산한다.
- 교대근무·여행 프리셋에서는 규칙성 항목을 제외하고 남은 가중치를 재분배한다.
- 수분 횟수만 입력하면 `수분 기록 습관`, 용량이 있으면 `기록된 섭취량`으로 표시한다.
- 충분·부족을 자동 판정하지 않고 개인 수분 제한 사용자는 추적을 끌 수 있다.
- 부위별 게이지는 `최근 부위별 훈련 부하` 또는 `회복 참고 게이지`로만 표현하며
  운동 가능·부상 위험·완전 회복을 판정하지 않는다.

## 5. 식단·AI 사진 추정

```text
영양소 추정량 = Σ(섭취량g ÷ 100 × 식품 DB의 100g당 영양소)
```

- 사진 추정은 최소·대표·최대 범위를 반환한다.
- 음식, 양, 조리법, 소스, 누락 음료를 사용자가 확인한 뒤 저장한다.
- 칼로리 부족·초과, 체중 변화, 질환 위험을 게임 보상에 연결하지 않는다.
- 한국 음식은 국가표준식품성분표를 우선하고 USDA FoodData Central을 보조로 사용한다.
- 건강검진·인바디 OCR은 보관·원문 비교용이며 게임 보상에 사용하지 않는다.
