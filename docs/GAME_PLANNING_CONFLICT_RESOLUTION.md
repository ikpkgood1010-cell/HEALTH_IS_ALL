# 새 게임 기획 충돌 해결 기록

상태: **RESOLVED / 2026-08-13**

## 적용 순서

1. 사용자가 대화에서 직접 확정한 최신 결정
2. 새 게임 기획 대화 1→2→4→5→6→7→8의 시간상 뒤 결정
3. 새 프롬프트·Stitch 에셋의 텍스트 의도
4. Master Prompt V10→V1과 TODO LIST
5. 개발기획 1~42 및 Claude 검토
6. 타 게임 기획서는 원칙 참고만 하며 명칭·수치·화면을 복제하지 않음

## 해결된 충돌

| 과거/상충안 | 확정안 | 처리 |
|---|---|---|
| 하단 `길드` 포함 5탭 | `홈/운동/식단/마이` 4탭 | 길드를 게임 내부로 이동 |
| 12시간·70% 자동 모험 | 5 일반방+1 보스의 지속 자동 전투 | 기존 API deprecated |
| 첫 용사 `아루` 1명 | 고정 직군 6인 파티 | 기존 아루 흐름은 레거시 |
| 전위대 1슬롯 | 탱커·전사·마법사·궁수·도적·치유사 | 6인 구조로 교체 |
| 용사별 대형 노드 수 불명확 | 시작 시 1명 무료 선택, 0계층 5개 영입 노드, 1~6계층 각 6개 전직 노드 | 사용자 확정 |
| 0계층 6개·랜덤 정령 초안 | 무료 첫 용사 제외 5개·영입/정령 확정·중복 없음 | 사용자 후속 확정 우선 |
| 정령 랜덤/중복 가능안 | 노드 해금 후 확정 부화, 중복 없음 | 사용자 확정 |
| 환생 시 전직 초기화 가능안 | 전직 차수·외형 영구 보존 | 사용자 확정 |
| 장비 세트 보존 문구 | 장비 인벤토리 없음 | 전직 외형·능력치 일괄 적용 |
| 게임 노드에 건강 기록 보관 | 원본 건강 기록은 건강 앱에만 존재 | 파생 건강 정수만 전달 |
| 확률형 포털/가챠 에셋 | 확률형 뽑기 없음 | 관련 에셋·프롬프트 폐기 |
| 5명 파티 이미지 | 6인 파티 고정 | 5명 이미지는 구성 참고만 사용 |
| 평면 2D 마을 지도 | 포근한 SD 3D 게임 공간 | 2D 지도는 동선 참고만 사용 |

## 남은 비차단 항목

- 용사별 고유 이름·성격·전직 명칭
- 각 층의 소형·중형 노드 개수와 비용 곡선
- 골드·건강 정수·별 조각의 정확한 획득/소비량
- 환생 최소 조건과 초월 특성 수치
- 마을 시설 개방 순서와 길드의 소셜 범위

위 항목은 기능·배치 구현을 막지 않으며 경제/콘텐츠 시뮬레이션 단계에서 확정한다.
